# Life Game

Life Game is a mobile-first gamified real-life progress system: complete meaningful real-world tasks to earn XP, level up categories, build streaks, unlock achievements and earn coins.

## Current version: v0.5

The repository currently contains a working single-page prototype in `index.html`.

### Included
- Today / Progress / Profile navigation
- Overall XP, levels, coins, streak and league
- Nine independently progressing life categories
- Tasks can contribute to up to three categories
- Category symbols displayed on every task
- Task completion and reversal
- Achievements
- Activity history
- Custom task creation
- Local browser persistence
- Mobile-first responsive UI

### Important
This is still a prototype. Progress is stored in browser `localStorage`; there is no real account authentication or cloud synchronization yet. Never treat the prototype account concept as secure authentication.

## Roadmap

1. Stabilize the game rules and UI.
2. Split the frontend into maintainable modules.
3. Add a real backend/authentication system and cloud save.
4. Add server-side validation for XP, coins, streaks and achievements.
5. Add missions, richer rewards, rarity, social features, friends, leagues and gifts.
6. Turn the web app into a PWA for a strong phone experience.
7. Package the mature product for iOS and Android.

The GitHub repository is the source of truth so the same project can keep evolving without changing its identity or losing its history.
